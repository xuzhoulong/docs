# 性能优化

> 开发技巧 · 更快、更省、更顺滑。本页为骨架内容,可按需继续补充。

## 关键指标(Core Web Vitals)

- **LCP** — 最大内容绘制,衡量加载速度
- **INP** — 交互到下一次绘制,衡量响应性
- **CLS** — 累积布局偏移,衡量视觉稳定性

## 常见优化手段

- **加载**:路由懒加载、代码分割、按需引入、压缩资源。
- **渲染**:虚拟列表、避免频繁回流、`key` 稳定唯一。
- **缓存**:合理设置强缓存/协商缓存、静态资源指纹。
- **图片**:使用 WebP/AVIF、懒加载、明确宽高避免抖动。

## 度量优先

> 先测量再优化:用 Performance / Lighthouse 定位瓶颈,避免凭感觉优化。
