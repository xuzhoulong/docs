# 调试技巧

> 开发技巧 · 高效定位问题。本页为骨架内容,可按需继续补充。

## 系统化排查思路

1. **复现** — 找到稳定复现的最小步骤。
2. **隔离** — 二分定位,缩小可疑范围。
3. **观察** — 加日志/断点,验证假设。
4. **修复** — 改完后回归,确认无副作用。
5. **总结** — 记录根因,沉淀为经验。

## 常用手段

- 断点调试优于盲目 `console.log`。
- 用 `try/catch` 打印完整堆栈,而非只打印 `message`。
- 网络问题先看请求头/响应体,再判断前后端。
- 环境差异用最小可复现仓库来验证。

## 心智提示

> 先让问题**稳定复现**,再谈修复;不能复现的 bug 大多是时序或环境问题。
